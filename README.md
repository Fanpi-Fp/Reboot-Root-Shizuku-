# Reboot (Root / Shizuku)

Reboot is the perfect, fast, and convenient tool for advanced users, allowing you to instantly reboot your device into any required mode.
⚠️ IMPORTANT: This application requires Root access OR Shizuku to function. Most features work seamlessly via Shizuku, but Safe Mode and Fast Reboot (Soft reboot) strictly require Root access!
Forget about complex hardware button combinations or typing commands in a terminal. With this app, you can manage your device's power with just a single tap.

Available Modes & Features:
- EDL (Emergency Download Mode) (Root / Shizuku)
- Fastboot / Bootloader (Root / Shizuku)
- Recovery (Root / Shizuku)
- Power Off (Root / Shizuku)
- Reboot (Standard reboot) (Root / Shizuku)
- Restart Launcher (Restart home screen) (Root / Shizuku)
- Restart System UI (Root / Shizuku)
- Safe Mode (Requires Root) ⚠️
- Fast Reboot (Soft reboot) (Requires Root) ⚠️

Key Features:

💧 Shizuku & Root Support: Works with both Root and Shizuku for maximum flexibility without full system modifications.
🌙 Dark Mode: Clean, comfortable look for night-time use.
🔄 Landscape Support: The layout perfectly adapts to both portrait and landscape screen orientations.
⚡ Speed & Minimalism: Lightweight, lightning-fast launch, and instant command execution.
The ultimate solution for flashers, developers, and power users who frequently work with custom ROMs and system tweaks.
